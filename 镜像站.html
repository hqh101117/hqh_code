pip镜像站

清华源：https://pypi.tuna.tsinghua.edu.cn/simple

豆瓣源：https://pypi.doubanio.com/simple

阿里源：http://mirrors.aliyun.com/pypi/simple

网易源：http://mirrors.163.com/pypi/simple

中科大源：http://pypi.mirrors.ustc.edu.cn/simple

临时换源命令：pip install +包名 -i +镜像站地址

单包永久换源命令：pip.exe install +包名 --trusted-host +镜像站地址

全局永久换源命令：pip.exe config set global.index-url +镜像站地址
